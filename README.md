# 飞书文档导出 HTML

一键把可正常阅读的飞书文档导出为单文件 HTML，离线可读。适用于管理员关闭导出、但文档仍可阅读的场景。

## 安装

需要 Chrome 117 或更高版本（已在 Chrome 157 验证）。

1. 打开 `chrome://extensions`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录

## 使用

1. 打开飞书文档（新版 docx，`/docx/` 或 `/wiki/`）
2. 点击工具栏扩展图标
3. 等待页面自动滚动收集内容；长文档可在右下角浮层点「取消」中止
4. 浏览器下载 `文档标题.html`

## 支持内容

标题、正文、列表、引用、标注块、代码块、表格、图片、画板/图表（快照或占位）。

## 不支持

旧版文档、电子表格、多维表格、幻灯片；评论与编辑工具栏；批量导出；Markdown/PDF。

## 已知限制

- 长文档导出期间页面会自动滚动收集内容，导出耗时随文档长度增加；可在进度浮层点「取消」中止，仍请勿关闭标签页。
- 画板/图表无法取得缩略图或 canvas 时输出占位块。
- 画板快照会临时放大画板容器、按 3 倍分辨率重绘后合成为一张图，再按内容边界裁掉空白画布并铺满栏宽；放大阅读更清晰，单张体积相应变大，导出期间画板区域会短暂变形，结束后自动复原。
- 依赖 iframe 的嵌入图优先用 HTML 解析器提取内部矢量 SVG（保留 viewBox 与图内样式，放大不失真）；取不到 SVG 时退化为截图，截图期间需保持该标签页在前台，失败时占位块内会写明原因。
- 图片依赖页面会话抓取；抓取失败时改用页面已渲染的像素快照，仍失败才保留原链接（离线不可见）。
- 导出外观跟随当前主题（深色模式导出深色）。
- 飞书改版可能导致选择器失效，需要更新 `content.js` 顶部的选择器常量。

## 权限

仅使用 `activeTab`、`scripting`，以及小组件 CDN（`lf-fb.feishupkg.com`）的读取权限——后者只用于从嵌入块中提取矢量 SVG。不上传任何数据。
